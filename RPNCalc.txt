1. WHAT IT DOES
----------------------------------------------------------------------------------------------------

RPNCalc is a Reverse Polish Notation (RPN) calculator for Far Manager. It is used in two ways:

  - a dialog, opened from the plug-ins menu (F11, "RPN Calculator"), that shows the stack and can be
    worked with the keyboard alone (section 3);
  - the Far command line, with the prefix "rpn:", for a quick calculation (section 4):

        rpn: 3 4 + 5 *

    The result is shown in a message box.

The stack and the angle mode are shared by the dialog and the command line and are kept between
sessions.

What RPN means

  In RPN the operands come first and the operator after them. The values are kept on a stack: X is
  the top of the stack, Y the level below it, and so on.

  - A number is pushed on the stack.
  - An operator takes its operands from the stack (the last two for a binary operator, X for a
    function) and pushes the result.

  Example, (3 + 4) * 5:

        3 4 + 5 *          ->  35

        3       stack: 3
        4       stack: 3 4
        +       stack: 7         (3 + 4)
        5       stack: 7 5
        *       stack: 35

  There are no parentheses: the order of the commands is the order of evaluation. For an operator
  that is not commutative, Y is the left operand and X the right one: "10 4 -" gives 6 and "2 3 ^"
  gives 8.


2. REQUIREMENTS AND INSTALLATION
----------------------------------------------------------------------------------------------------

  - Far Manager 3.0 (build 4000 or later), 32 or 64-bit: use the DLL of the same bitness as Far
    (X86\RPNCalc.dll or x64\RPNCalc.dll).

  - Put RPNCalc.dll, the help file (RPNCalcEng.hlf) and the language file (RPNCalcEng.lng)
    together in a folder of their own under the Far plug-ins folder, for example

        %FARHOME%\Plugins\RPNCalc\

    and restart Far. Far looks for the help and language files in the folder of the DLL, so the
    folder must not be shared with another plug-in.

  - To calculate, press F11 and choose "RPN Calculator", or type "rpn:" followed by the commands in
    the Far command line. The plug-in never opens a panel.


3. THE DIALOG
----------------------------------------------------------------------------------------------------

The dialog shows 8 stack levels (level 1 is X, at the bottom, next to the input line), the input
line, and a status line with the angle mode (radians or degrees) and the stack depth, or the last
error. The stack can be deeper than 8 levels (up to 10000); only the first 8 are shown.

Type one or more commands in the input line, separated by white space, and press Enter. The results
go to the stack and the line is cleared. If the line contains an error, the stack and the angle mode
go back to the state they had before the line, the error is shown in the status line, and the text
stays in the input line so that it can be corrected.

Keys

  Enter            Evaluate the line. On an empty line: DUP.
  + * / ^          On an empty line: apply the operator at once.
  Backspace        On an empty line: DROP (remove X).
  Del              On an empty line: CLR (clear the whole stack).
  Ctrl+Backspace   UNDO. It works also when the line contains text; the text is left untouched.
  Alt+F1           "-"   (Y - X)
  Alt+F2           chs   (change sign)
  Alt+F3           inv   (1/X)
  Alt+F4           swap
  Ctrl+Enter       Evaluate, then close the dialog and insert X into the Far command line, with
                   all the digits it needs. On an empty line it does not DUP: it only inserts X.
                   If the stack is empty, the status line says so and the dialog stays open.
  F1               Help.
  Esc              Close the dialog. The stack is saved.

  - "Empty line" means a line with no characters at all. A line that holds only spaces is not empty:
    Backspace, Del and the operator keys then edit the line as usual.
  - The text already typed is evaluated before an Alt+F1 ... Alt+F4 command, as part of the same
    line: if it contains an error, nothing is changed and the text stays in the line. If the
    terminal intercepts Alt+F4, type "swap".


4. THE COMMAND LINE
----------------------------------------------------------------------------------------------------

Type "rpn:" followed by the commands in the Far command line and press Enter:

    rpn: 2 pi *

  - A message box shows X and the stack depth ("Stack is empty" if nothing is left).
  - If the line contains an error, the box shows the error and the stack is left as it was.
  - F1 in the message box opens the help.
  - The stack and the angle mode are the same as in the dialog. To copy X from the dialog to the
    command line, press Ctrl+Enter in the dialog.


5. COMMANDS
----------------------------------------------------------------------------------------------------

Commands are separated by white space; several can be on one line. Their names are not case
sensitive.

Numbers

  3.14   3,14   -2   1e-5

  - Both "." and "," are accepted as the decimal separator.
  - Binary 1010#B, hexadecimal FF#H, decimal integer 255#D. The sign is optional, the digits are 0-9
    and A-F, the suffix and the digits are not case sensitive, and the absolute value must not
    exceed 2^53.
  - inf, nan and hexadecimal floating-point numbers (such as 0x1p3) are not accepted; neither is a
    number too large for a double.

Binary operators (Y op X; the result replaces both operands)

  +  -  *  /  ^  **  %  mod  atan2  min  max

  - "^" and "**" are the power Y^X. "%" and "mod" are the remainder, with the sign of the dividend.
  - atan2 computes atan2(Y, X), in the current angle mode.
  - Division by zero (/, %, mod) is an error.

Functions (act on X)

  neg  chs           change sign
  abs                absolute value
  inv                1/X (X must not be 0)
  sq                 X squared
  sqrt               square root (X must not be negative)
  cbrt               cube root
  exp                e raised to the power X
  ln                 natural logarithm (X must be greater than 0)
  log                base 10 logarithm (X must be greater than 0)
  log2               base 2 logarithm (X must be greater than 0)
  sin  cos  tan      X is in the current angle mode
  asin  acos         X must be in -1..1; the result is in the current angle mode
  atan               arc tangent, in the current angle mode
  sinh  cosh  tanh   hyperbolic functions (not affected by the angle mode)
  fact               factorial of an integer X in 0..170, rounded to the nearest integer (170! is
                     the largest value that fits)
  floor              largest integer not greater than X
  ceil               smallest integer not less than X
  round              nearest integer, halves away from zero
  int                integer part (truncation toward zero)

  - sin, cos and tan: a result below the resolution of the argument (for example "pi sin",
    "pi 2 / cos", or "180 sin" in degrees) is replaced by exactly 0. Small results of small
    arguments ("1e-16 sin") are kept.
  - A result that is not finite is an error.

Stack commands

  dup           duplicate X
  drop          remove X
  swap          exchange X and Y
  over          copy Y on top
  rot           rotate the top three levels: Z -> X, X -> Y, Y -> Z
  clr  clear    clear the stack
  sum           replace the whole stack with the sum of its entries
  avg           replace the whole stack with the average of its entries

Constants

  pi  e

Angles

  rad           radians (default)
  deg           degrees

  The mode applies to sin, cos, tan, asin, acos, atan and atan2. The hyperbolic functions are not
  affected.

Undo

  undo          restore the stack and the angle mode to the state before the last command that
                changed them

  - Every command that changes something is one step, numbers included: "3 4 +" takes three undos.
    A command that changes nothing (swap with two equal entries, for example) is not recorded.
  - Up to 100 steps are kept while Far is running, also between the dialog and the command line.
    They are not saved in the settings. There is no redo.
  - With an empty history the error "Nothing to undo" is shown.
  - undo can be typed in the input line, after the "rpn:" prefix, or given with Ctrl+Backspace in
    the dialog.

Number bases

  bin  hex  dec    change the display of X, which must be an integer (|X| <= 2^53):

      255 bin      ->  11111111#B
      255 hex      ->  FF#H
      FF#H dec     ->  255

  - "dec" gives a plain integer, never with an exponent. Negative numbers are shown with a minus
    sign (-10 bin gives -1010#B), not in two's complement.
  - The value itself does not change: it is only shown in another base. dup, over, swap and rot keep
    the display form. The results of later operations are shown in the normal form.


6. ERRORS AND PERSISTENCE
----------------------------------------------------------------------------------------------------

Errors

  A line that contains an error is cancelled as a whole: the stack, the angle mode and the undo
  history return to the state they had before the line. The error is shown in the status line of
  the dialog, or in the message box of "rpn:".

  The errors are: not enough operands, division by zero, a result that is not finite, a full stack,
  nothing to undo, an unknown command, an invalid number or digit, a number or an integer that is
  too large, a value that is not an integer, and a value outside the domain of a function (square
  root of a negative number, logarithm of a number that is not positive, asin or acos outside
  -1..1, factorial of a number that is not an integer in 0..170). The help (F1, "Errors and
  persistence") explains each of them.

Persistence

  - The stack and the angle mode are stored in the Far settings of the plug-in when the dialog is
    closed and after every successful "rpn:" line. They are read once, the first time the plug-in is
    used in a Far session.
  - The stack is stored as text, in the same syntax that the calculator accepts, with 17
    significant digits so that every value is read back exactly. The display form set by bin, hex
    and dec is kept. Entries that cannot be read back are skipped.
  - The undo history is not saved.


7. LIMITS
----------------------------------------------------------------------------------------------------

  - Stack depth: 10000 entries. The dialog shows the first 8 levels.
  - Undo: 100 steps.
  - Number bases: X must be an integer with |X| <= 2^53.
  - Numbers are IEEE double precision; results are shown with up to 15 significant digits.
  - A decimal number written with 512 characters or more is rejected.
  - A command that would produce a result that is not finite (overflow, ln of a number that is not
    positive, and so on) is an error and changes nothing.
  - If memory runs out, the plug-in reports it ("Out of memory" in the status line of the dialog,
    or a message box) and Far goes on.


8. LANGUAGES
----------------------------------------------------------------------------------------------------

Every text that the plug-in shows (the dialog, the message boxes, the errors) comes from a Far
language file (.lng) in the folder of the DLL.

  RPNCalcEng.lng   English

The help (F1) is a separate file, RPNCalcEng.hlf.

How it works

  - Far loads the file whose ".Language=" line names its interface language (Options > Languages).
    If there is no such file, it loads the English one.
  - The English texts are also built into the DLL. Without any language file, the plug-in works in
    English.

Adding a language (no recompilation is needed)

  1. Copy RPNCalcEng.lng to RPNCalc<Language>.lng in the folder of the DLL.
  2. On the first line, change the language to the name that Far uses for it (the word before the
     comma, for example "German"; the text after the comma is only a description).
  3. Translate the text of each message, between the double quotes.
  4. If the translation has characters outside ASCII, save the file as UTF-8 with BOM (or UTF-16).
     Restart Far.

Rules for a language file

  - A message is a line that starts with a double quote. Far numbers the messages from 0 in the
    order in which they appear, and the plug-in asks for them by number: keep every message, in the
    same order.
  - Lines that do not start with a double quote (the // lines, the empty lines) are comments.
  - "%s" is replaced by a value (a number, a command, the value of X, an error text): keep it, once,
    in the place where it reads naturally. The comment above each message says what it stands for.
    A text without "%s" is shown as it is.

What is not translated

  - The names of the commands (dup, swap, sin, ...) and the prefix "rpn:".


9. BUILDING FROM SOURCE
----------------------------------------------------------------------------------------------------

The plug-in is a single C++ file, rpncalc.cpp, plus the version resource rpncalc.rc (file version,
author and year, shown in the Details tab of the DLL properties; keep its version equal to the one
in GetGlobalInfoW, the PLUGIN_VER_* values at the top of the source: build.bat stops if they differ).
Install MSYS2 (found
automatically, usually in C:\msys64; otherwise set MSYS2_ROOT). Then, from the Windows command
prompt, in the folder of the project:

    build.bat          builds both versions, compressed with UPX when it is found
    build.bat x64      builds .\x64\RPNCalc.dll (64 bit)
    build.bat x86      builds .\X86\RPNCalc.dll (32 bit)
    build.bat noupx    does not compress the DLLs (can be combined with x64 or x86)
    build.bat zip      also creates RPNCalc-<version>.zip, with the folders built, RPNCalc.txt
                       and LICENSE (needs tar.exe, which is part of Windows 10 and later)

RPNCalcEng.lng and RPNCalcEng.hlf are copied next to each DLL, so that the folder is ready to be
copied into the Far plug-ins folder.

  - Compilers. The 64 bit DLL is built with the g++ of the MSYS2 environment mingw64 (the smallest
    DLL) or, if it is missing, ucrt64; the 32 bit DLL with the one of mingw32. The environments
    that are tried can be set with the variables ENV64 and ENV32. A missing compiler is not
    installed: build.bat prints the pacman command that installs it (mingw-w64-x86_64-gcc,
    mingw-w64-ucrt-x86_64-gcc or mingw-w64-i686-gcc). The package mingw-w64-x86_64-gcc, for the
    environment mingw64, gives the smallest 64 bit DLL and a DLL that needs only msvcrt.dll; a DLL
    built with ucrt64 needs the UCRT (Windows 10, or Windows 7/8.1 with the Universal C Runtime update).
  - plugin.hpp of Far 3 is taken from the folder of the project, from the folder FARSDK (default
    .\PluginSDK; its subfolder Headers.c is tried too, as in Far's own PluginSDK) or from the
    PluginSDK\Headers.c folder of an installed Far; if it is not found, it is downloaded once with
    curl from the official Far Manager repository, into the folder of the project.
  - UPX is used when upx.exe is found (the MSYS2 folders or the PATH); it roughly halves the size
    of the DLLs. It is not installed by build.bat, which prints the package for the environment in
    use (mingw-w64-x86_64-upx, mingw-w64-ucrt-x86_64-upx or mingw-w64-i686-upx). Some antivirus
    programs are suspicious of UPX-packed files: use "noupx" for a DLL that is not packed.
  - Both DLLs are linked with -Wl,--kill-at: in the 32 bit one, the stdcall exports get the
    undecorated names that Far looks for. After linking, build.bat checks with objdump that
    GetGlobalInfoW, SetStartupInfoW, GetPluginInfoW and OpenW are exported with those names, and
    deletes the previous DLL before linking, so that a failed build never leaves an old one behind.

Compile options (-D on the compiler command line)

  RPN_MIN_FAR_BUILD     the oldest Far build that loads the plug-in (default 4000)
  RPN_KEEP_FUNCTEXCEPT  keep the exception helpers of libstdc++ instead of the small ones in the
                        source (build.bat tries again with it when the first compilation fails)

Structure of the source

  - Engine: a class that holds the stack (a vector of {value, base} entries), the angle mode and the
    undo history. Eval() splits a line into tokens and executes them one by one. Before the line it
    takes a copy of the state; on a user error (RpnError) it restores the copy, so every line is
    atomic. The undo snapshots are shared pointers, so the history is cheap to copy.
  - Parser and formatter: numbers are read and written with the C runtime (strtod, snprintf), not
    with iostream or locale classes, so that the result does not depend on the Windows locale and
    the libstdc++ locale code stays out of the DLL. The same syntax is used for typing, for the
    saved stack and for the text inserted in the command line.
  - Persistence: LoadState() and SaveState(), through the settings API of Far.
  - Dialog: DlgProc handles DN_CONTROLINPUT for the input line, so the keys of section 3 are
    intercepted before Far's own editing. Other messages, including F1, go to the default dialog
    procedure. No C++ exception may leave DlgProc or OpenW: a failure such as lack of memory is
    reported in the status line (or in a message box) instead of stopping Far.
  - Exports: GetGlobalInfoW, SetStartupInfoW, GetPluginInfoW and OpenW. The plug-in registers the
    command prefix "rpn" and one entry in the plug-ins menu. OpenW starts the dialog or, for the
    command line, runs one line and shows the result.
  - Messages: every text shown to the user is a numbered message (the enum M_TITLE ... M_COUNT).
    GetMsg() asks Far for it, and Far reads it from the language file; if Far returns nothing (no
    .lng file) the English text built into the DLL (kDefaultMsg) is used. FormatMsg() puts a value
    in place of "%s".
  - Identity: PLUGIN_NAME, PLUGIN_DESC, PLUGIN_AUTHOR and PLUGIN_VER_* at the top of the source are
    used by GetGlobalInfoW (the plug-in information that Far shows).
  - Size: the DLL is kept small by not using <iostream>, <sstream>, <locale> and <unordered_map>, by
    replacing the default terminate handler and the libstdc++ exception helpers with small ones, and
    by linking the C++ runtime statically, with garbage collection of the unused sections.

To add a message to the plug-in: add its identifier to the enum before M_COUNT, its English text at
the same position in kDefaultMsg, and the message at the same position in every .lng file, with a
comment above it that says what "%s" stands for. The enum, kDefaultMsg and RPNCalcEng.lng list the
messages in the same order, with the same text.
